# Model Storage
Plaats hier je grote .glb bestanden (voor.glb, constructie.glb, na.glb).
Deze map wordt NIET meegenomen in de website build om foutmeldingen over bestandsgrootte te voorkomen.

Om de modellen te gebruiken:
1. Push je wijzigingen naar GitHub.
2. Ga naar het bestand op GitHub en klik op "Raw".
3. Gebruik die URL in `src/components/ARViewer.tsx`.
